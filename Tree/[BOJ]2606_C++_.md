## 문제

1번 컴퓨터가 바이러스에 걸렸을 때, **직접 혹은 간접적으로 연결되어 감염되는 컴퓨터의 수**를 구하는 문제입니다.

- 총 `n`개의 컴퓨터가 있고, 일부 컴퓨터 간에는 네트워크 연결이 주어집니다.
- 연결 정보는 **양방향**입니다.
- 1번 컴퓨터에서 시작해 **DFS 방식으로 전파되는 바이러스 감염**을 시뮬레이션해야 합니다.

## 풀이

### 아이디어

1. **그래프를 인접 리스트로 표현**
    - 컴퓨터 번호를 정점으로 보고, 연결 관계를 인접 리스트(`vector<vector<int>>`)로 저장
2. **DFS로 감염 전파**
    - 1번 컴퓨터에서 시작하여 방문하지 않은 인접 컴퓨터로 재귀 탐색
    - `infected[i]`가 `true`면 이미 감염된 상태
3. **감염된 컴퓨터 수 계산**
    - `infected` 배열에서 `true`인 개수를 세되,
        
        **1번 컴퓨터는 제외**하고 출력 (`-1`)
        

### 코드

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

void infect(vector<vector<int>>& adjs, int here, vector<bool>& infected) {
    infected[here] = true;

    for (int i = 0; i < adjs[here].size(); i++) {
        int there = adjs[here][i];
        if (!infected[there]) {
            infect(adjs, there, infected);
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL); cout.tie(NULL);

    int n; cin >> n;
    int n_of_adjs; cin >> n_of_adjs;

    vector<vector<int>> adjs(n + 1);

    for (int i = 0; i < n_of_adjs; i++) {
        int a, b;
        cin >> a >> b;
        adjs[a].push_back(b);
        adjs[b].push_back(a);
    }

    vector<bool> infected(n + 1, false);
    infect(adjs, 1, infected);

    // 1번 컴퓨터 제외
    cout << count(infected.begin(), infected.end(), true) - 1 << "\n";

    return 0;
}
```

### 해결 과정에서 어려웠던 점

1. **그래프 구성 방법**
    - 컴퓨터 번호를 정점으로 보고, 연결 관계를 **인접 리스트**로 구성하는 방법에서 약간 혼란이 있었음.
    - 간선이 입력될 때, **양방향으로 모두 저장**해야 한다는 점이 중요함 (`adjs[a].push_back(b);`, `adjs[b].push_back(a);`)

### 발전 가능한 아이디어

1. **감염 수만 세고 싶다면 불필요한 저장 없이 count 변수로도 처리 가능**
    - DFS 함수 내에서 감염될 때마다 `count++` 방식으로 메모리 아끼는 구현도 가능
