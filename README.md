# algorithm
알고리즘 강의 기반 문제 풀이 및 관련 알고리즘 학습 내용을 정리한 저장소입니다.

## 📁 폴더 구조

- 알고리즘 유형별로 폴더를 구분하였습니다.  
  예: `Brute Force/`, `Graph/`, `Sorting/`

## 📄 파일명 규칙

- **바킹독 강의 기반 문제**는 파일명 앞에 `bkd_` 접두사를 붙입니다.
- 그 외 문제는 출처에 따라 자유롭게 작성하되, 일관성 있게 정리합니다.

## 📝 커밋
### Type
{Keyword}: [{문제 출처}]{#Issue}

Type
- 'solve': 풀이에 성공한 새 문제 추가
- 'fail': 풀이에 실패한 새 문제 추가
- 'fix': 기존 풀이의 버그 수정
- 'feat': 코드 구조 개선 (로직 변경 없이)
- 'improve': 새로운 풀이법 추가
- 'docs': 문서 수정
