## 문제

무방향 그래프가 주어졌을 때, 연결 요소(connected component)의 개수를 구하는 문제입니다.

- 정점 수 `n`, 간선 수 `m`이 주어짐
- 정점은 `1번`부터 `n번`까지 존재
- 간선으로 이어진 정점들은 하나의 **연결 요소**로 간주
- **총 몇 개의 연결 요소가 있는지 출력**

## 풀이

### 아이디어

1. **그래프 구성**
    - 무방향 그래프이므로, `u - v` 간선이 주어지면 `u → v`, `v → u` 모두 연결해야 함
    - 인접 리스트(`vector<vector<int>>`)로 그래프를 저장
2. **DFS로 연결 요소 탐색**
    - `visited` 배열을 사용하여 이미 방문한 정점을 다시 탐색하지 않도록 함
    - 1번 노드부터 n번 노드까지 순차적으로 검사하면서,
        
        방문하지 않은 노드가 나오면 **새로운 연결 요소의 시작**으로 보고 DFS 수행
        
    - DFS가 끝날 때마다 연결 요소 개수 `cnt`를 증가시킴

### 코드

```cpp
#include <iostream>
#include <vector>

using namespace std;

// DFS: 현재 정점에서 연결된 모든 정점 방문
void dfs(int here, vector<vector<int>>& adjs, vector<bool>& visited) {
    visited[here] = true;

    for (int i = 0; i < adjs[here].size(); i++) {
        int there = adjs[here][i];
        if (!visited[there]) {
            dfs(there, adjs, visited);
        }
    }
}

// DFS 전체 호출: 연결 요소(컴포넌트) 개수 세기
int dfsAll(int n, vector<vector<int>>& adjs) {
    vector<bool> visited(n + 1);
    int cnt = 0;

    for (int i = 1; i <= n; i++) {
        if (!visited[i]) {
            cnt++;
            dfs(i, adjs, visited);
        }
    }

    return cnt;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(NULL); cout.tie(NULL);

    int n, m;
    cin >> n >> m;

    vector<vector<int>> adjs(n + 1);

    int u, v;
    // 무향 그래프 입력
    for (int i = 0; i < m; i++) {
        cin >> u >> v;
        adjs[u].push_back(v);
        adjs[v].push_back(u);
    }

    cout << dfsAll(n, adjs);

    return 0;
}

```

### 해결 과정에서 어려웠던 점

1. **연결 요소 개수 세는 구조 설계**
    - 단순히 DFS로 순회하는 것 외에, **여러 번 DFS를 호출하면서 연결 요소를 센다는 아이디어**가 처음엔 어려웠음
    - `dfsAll` 함수처럼 전체 노드를 돌며 방문 여부를 체크하고 DFS를 수행하는 구조로 해결
