## 문제

- 정점의 개수 `n`과 `n x n` 인접 행렬이 주어짐
- `i → j`로 **경로가 존재하는지 여부(직접 또는 간접 연결)**를 판단하여 `n x n` 행렬로 출력
- 즉, **그래프의 모든 정점 쌍 (i, j)에 대해 i에서 j로 갈 수 있는가를 판단하는 문제**

## 풀이

### 아이디어

- 정점 `i`에서 DFS를 시작하여, 도달할 수 있는 모든 정점을 `visited` 배열에 기록
- 정점 `i`에서 DFS 결과로 `visited[j] == true`이면, `i → j` 경로 존재 → `1` 출력
- 이를 `i = 0 ~ n-1`에 대해 반복 수행하여 `n x n` 결과 출력

### 코드

```cpp
#include <iostream>
#include <vector>

using namespace std;

// DFS: here 노드에서 도달 가능한 모든 노드를 visited에 기록
void dfs(int here, vector<vector<int>>& adj, vector<bool>& visited) {
    for (int there = 0; there < adj.size(); there++) {
        // 연결되어 있고 아직 방문하지 않았다면
        if (adj[here][there] == 1 && !visited[there]) {
            visited[there] = true;
            dfs(there, adj, visited);
        }
    }
}

int main() {
    int n;
    cin >> n;

    vector<vector<int>> adj(n, vector<int>(n));

    // 인접 행렬 입력
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            cin >> adj[i][j];
        }
    }

    // 각 노드 i에 대해 도달 가능한 노드 j를 찾음
    for (int i = 0; i < n; i++) {
        vector<bool> visited(n, false);
        dfs(i, adj, visited);

        for (int j = 0; j < n; j++) {
            cout << (visited[j] ? 1 : 0) << " ";
        }
        cout << "\n";
    }

    return 0;
}
```

### 해결 과정에서 어려웠던 점

1. **자기 자신에 대한 경로 처리**
    - 처음에는 DFS에서 `visited[here] = true`를 먼저 설정했지만,
        
        이렇게 하면 `i → i`가 항상 1로 출력되어 **자기 자신으로 가는 경로가 없는데도 1이 출력됨**
        
    - 따라서 `visited[there] = true`를 **반복문 내부에서만 설정**하여,
        
        **간선이나 경로가 실제로 존재할 때만 방문 표시**되도록 수정
        
2. **인접 행렬을 이용한 그래프 입력**
    - 인접 행렬을 이용해 그래프를 입력 받는 코드를 처음 작성해봐서 문제 이해와 풀이 작성에 어려움을 느낌
    - `adj[i][j]`로 입력받은 값을 바탕으로, **어느 노드와 연결되어 있는지 판단**

### 발전 가능한 아이디어

- **플로이드-워셜 알고리즘**을 사용하면 O(n³) 시간복잡도로 전체 경로 정보를 한 번에 계산 가능
